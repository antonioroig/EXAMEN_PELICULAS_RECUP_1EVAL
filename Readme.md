# EXAMEN_PELÍCULAS — RECUPERACIÓN 1ª EVALUACIÓN

Este directorio contiene la plantilla para el examen de recuperación. El archivo principal a modificar es `main.js`.

Instrucciones rápidas:

- Mantén los datos en `peliculas` tal y como están.
- Implementa las funciones marcadas con `TODO` en `main.js`:
  - `cargarPeliculas()`
  - `crearBotonesFiltro()`
  - `inicializarBotonesFavoritos()`
  - `inicializarBotonesDetalles()`
  - `ManejadorEliminar()`
  - `filtrarPorGenero(genero)`
  - `mostrarFavoritos()`
- Al cargar la página se llama a `init()` que ejecuta la inicialización. No cambies esa llamada.

Archivos incluidos:

- `index.html`: estructura mínima y templates requeridos.
- `main.js`: datos y stubs para implementar.

Cómo probar localmente:

1. Abre `index.html` en un navegador.
2. Implementa las funciones en `main.js`.
